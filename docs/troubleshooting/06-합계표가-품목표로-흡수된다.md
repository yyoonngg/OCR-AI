# 합계 표가 품목 표 마지막 행으로 흡수된다 (회귀)

- 날짜: 2026-08-17
- 대상: `backend/app/layout.py` — `_try_add`
- 상태: 해결
- 성격: **[04](04-줄바꿈된-셀에서-표가-끊긴다.md)를 고치다 만든 회귀**

## 증상

줄바꿈 셀을 허용하도록 표 판정을 완화한 직후, 거래명세서 샘플에서 표가 3개에서
2개로 줄었다. 합계 표가 품목 표의 **마지막 행에 통째로 빨려 들어갔다.**

```
[표 4x4]
  | 품목                     | 수량 | 단가       | 금액
  | 문서 OCR 엔진 라이선스    | 1   | 8,400,000 | 8,400,000
  | 업무 자동화 컨설팅        | 40  | 150,000   | 6,000,000
  | 온프레미스 설치 및 교육   | 1   | 1,200,000 공급가액 부가세(10%) 합계금액
                                   | 1,200,000 15,600,000 1,560,000 17,160,000
```

## 원인

합계 표의 행(`공급가액 | 15,600,000`)은 품목 표 기준으로 보면
**첫 열(품목)과 둘째 열(수량)이 비어 있고 셋째·넷째 열만 채워진 행**이다.

새 규칙은 "같은 열에 가로로 떨어진 줄이 있는가"만 봤기 때문에 충돌이 없었고,
이 행이 정상적으로 표에 얹혔다. 그 뒤 [05](05-세로가운데정렬-라벨에서-행이-어긋난다.md)의
"첫 열이 없는 밴드는 가까운 행에 붙인다" 규칙이 이걸 **줄바꿈된 셀로 취급**해
마지막 행에 병합해 버렸다.

가로 절단으로 먼저 갈렸어야 했지만, 두 표 사이 간격이 38px로 임계값
(줄 높이 33 × 1.2 = 39.6)에 아슬아슬하게 못 미쳤다.

## 해결 — 첫 열이 비었을 때 열 개수로 구분

첫 열이 빈 행은 두 가지 중 하나다.

- **셀 하나가 줄바꿈된 것** → 채워진 열이 **하나뿐**이다
- **다른 표가 시작된 것** → 채워진 열이 **여럿**이다

```python
if 0 not in buckets:
    if len(buckets) > 1:
        return None   # 새 표가 시작됐다
```

합계 표 행은 두 열(단가·금액 위치)에 걸쳐 있으므로 여기서 걸려 분리된다.

## 검증

```
[표 5x2] 문서번호 | AX-2026-0817-013 ...
[표 4x4] 품목 | 수량 | 단가 | 금액 ...
[표 3x2] 공급가액 | 15,600,000
         부가세(10%) | 1,560,000
         합계금액 | 17,160,000
```

교재 표(`7×2`, `4×2`)도 그대로 유지된다.
